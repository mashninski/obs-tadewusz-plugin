# obs-tadewusz-plugin

Плагін для OBS і Twitch, з якім стрым кіруецца балами канала. Адзін док у OBS, тры функцыі:

- **Галасаванне.** Гледачы дадаюць гульні ў спіс і аддаюць за іх балы канала. Спіс з трохлітарнымі
  кодамі і баламі ідзе на экран, раўнды завяршаюцца з таймерам і правілам пераносу балаў.
- **Бягучы радок.** Аб’явы стрымера па раскладзе і платныя паведамленні гледачоў у плашцы на экране.
- **Музыка.** Замовы песень Spotify і відэа YouTube за балы, чарга, оверлей з хваляй гуку.

Інтэрфейс і адказы гледачам — па-беларуску.

## Як гэта працуе

```
OBS ── tadewusz.lua ──► ядро (Node.js, 127.0.0.1:18745) ◄──► Twitch: Helix + адно злучэнне EventSub
 │                         │  SQLite: пазіцыі, балы, журнал       ▲
 │                         │  рэзервовыя копіі, DPAPI для токенаў │
 ├─ док ───────────────────┤                                      │
 ├─ оверлей галасавання ───┤                                      │
 ├─ бягучы радок ──────────┤                                      │
 └─ оверлей музыкі ────────┘── мозг музыкі (у браўзеры OBS) ──────┘ праз ядро
                                Spotify Web API, YouTube
```

- **Ядро** (`core/`) запускаецца разам з OBS і завяршаецца, калі OBS закрываюць. Яно трымае адзін
  уваход у Twitch на ўсю праграму, адно злучэнне EventSub і базу галасавання.
- **Балы не губляюцца.** Кожная змена балаў запісваецца ў журнал (`ledger`) у той жа транзакцыі,
  што і сама змена. Статус пакупкі ў Twitch (выканана або вернута) ставіцца толькі пасля таго, як
  рашэнне ўжо ў базе. Пакупкі, зробленыя, пакуль сувязі не было, застаюцца ў чарзе Twitch і даганяюцца
  зверкай.
- **Рэзервовыя копіі** робяцца самі: раз у 10 хвілін пасля змен і раз на дзень у асобную тэчку
  (90 дзён). Кожная копія — цэлая база, правераная `integrity_check`.
- **Музыка** (`web/src/music/`) працуе ў браўзеры OBS: так плэер YouTube і хваля гуку бліжэй да
  эфіру. Да Twitch яна звяртаецца праз ядро і не можа змяняць узнагароды галасавання.

## Галасаванне

| Узнагарода | Што робіць |
|---|---|
| Дадаць гульню ў спіс | новая пазіцыя з назвы або спасылкі Steam |
| N на гульню са спіса | +N балаў пазіцыі па трохлітарным кодзе |

- Дадаванне можна вярнуць гледачу, пакуль за гульню ніхто не галасаваў; галасы пацвярджаюцца адразу.
- Балы можна перанесці з адной пазіцыі на іншую (напрыклад, калі гульню дадалі двойчы).
- **Новы раўнд:** пераможцу застаецца 1/5 балаў, месцам 2–6 — 2/3, астатнім — без змен. Знізу
  выбывае па адной пазіцыі на кожныя поўныя 5: 6–10 пазіцый — 1, 11–15 — 2 і г. д.

## Усталяванне

Патрэбны Windows, OBS 30+ з уключаным WebSocket-серверам і Node.js 24.

```bash
npm install
npm run build
npm run install-app
```

Праграма ўсталюецца ў `%USERPROFILE%\obs-tadewusz\app`, даныя — у `%USERPROFILE%\obs-tadewusz\data`.
Каманда пакажа, што дадаць у OBS:

1. **Інструменты → Скрыпты:** `app\obs\tadewusz.lua` — праграма будзе запускацца разам з OBS.
2. **Докі → Карыстальніцкія докі браўзера:** `…\obs\start.html?page=dock`.
3. **Крыніцы:** «Tadewusz · Галасаванне» (з’явіцца пасля скрыпту), «Браўзер» з
   `start.html?page=ticker&source=…` для бягучага радка і `start.html?page=music` для музыкі.
   Поўныя адрасы — у доку, укладка «Стан».
4. **Док → Падключэнні:** Client ID свайго Twitch-прыкладання (тып Public) і ўваход у Twitch,
   пароль OBS WebSocket, Client ID прыкладання Spotify. У Spotify Dashboard дадайце Redirect URI
   `http://127.0.0.1:18745/callback.html`.

## Распрацоўка

```bash
npm test            # тэсты ядра (node:test) і музыкі (Vitest)
npm start           # ядро з даведкай у кансолі
npm run dev         # Vite для дока і оверлеяў (API — ад запушчанага ядра)
```

```
core/       ядро: HTTP, Twitch, OBS, галасаванне, бягучы радок, сховішча
web/        док і оверлеі (Preact, TypeScript); web/src/music — мозг музыкі
shared/     код, агульны для ядра і старонак
obs/        скрыпт OBS, запуск ядра і старонка чакання
tests/      тэсты ядра
assets/     значкі ўзнагарод Twitch (загружаюцца ўручную ў панэлі Twitch)
```
