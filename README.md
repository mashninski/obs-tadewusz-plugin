# obs-tadewusz-plugin

Плагін для OBS і Twitch, з якім стрым кіруецца балами канала. Адзін док у OBS, пяць функцый:

- **Галасаванне.** Гледачы дадаюць гульні ў спіс і аддаюць за іх балы канала. Спіс з трохлітарнымі
  кодамі і баламі ідзе на экран, раўнды завяршаюцца з таймерам і правілам пераносу балаў.
- **Бягучы радок.** Аб’явы стрымера па раскладзе і платныя паведамленні гледачоў у плашцы на экране.
  Паведамленні гледачоў агучвае лакальная мадэль OmniVoice — кожны раз іншым з 25 галасоў-персанажаў.
- **Музыка.** Замовы песень Spotify і відэа YouTube за балы, чарга, оверлей з хваляй гуку.
- **Інтро / Аўтра.** Сцэна чакання перад стрымам: адлік, спасылкі з QR-кодамі і кліпы канала ў перамешаным
  парадку (афіцыйны плэер Twitch, без спампоўвання). Сцэна ў канцы стрыму — надпіс, спасылкі, кліпы
  і рэйд з дока: спіс каналаў у эфіры, картка рэйду і адлік на экране.
- **Сезон.** Празрыстая крыніца па-над сцэнай: павольна лётаюць прывіды, сняжынкі, лісце або пялёсткі —
  ці свае карцінкі стрымера.

Інтэрфейс і адказы гледачам — па-беларуску.

## Як гэта працуе

```
OBS ── tadewusz.lua ──► ядро (Node.js, 127.0.0.1:18745) ◄──► Twitch: Helix + адно злучэнне EventSub
 │                         │  SQLite: пазіцыі, балы, журнал       ▲
 │                         │  рэзервовыя копіі, DPAPI для токенаў │
 ├─ док ───────────────────┤                                      │
 ├─ оверлей галасавання ───┤                                      │
 ├─ бягучы радок ──────────┤                                      │
 └─ оверлей музыкі ────────┘── мозг музыкі (у браўзеры OBS) ──────┘ праз ядро
                                Spotify Web API, YouTube
```

- **Ядро** (`core/`) запускаецца разам з OBS і завяршаецца, калі OBS закрываюць. Яно трымае адзін
  уваход у Twitch на ўсю праграму, адно злучэнне EventSub і базу галасавання.
- **Балы не губляюцца.** Кожная змена балаў запісваецца ў журнал (`ledger`) у той жа транзакцыі,
  што і сама змена. Статус пакупкі ў Twitch (выканана або вернута) ставіцца толькі пасля таго, як
  рашэнне ўжо ў базе. Пакупкі, зробленыя, пакуль сувязі не было, застаюцца ў чарзе Twitch і даганяюцца
  зверкай.
- **Рэзервовыя копіі** робяцца самі: раз у 10 хвілін пасля змен і раз на дзень у асобную тэчку
  (90 дзён). Кожная копія — цэлая база, правераная `integrity_check`.
- **Музыка** (`web/src/music/`) працуе ў браўзеры OBS: так плэер YouTube і хваля гуку бліжэй да
  эфіру. Да Twitch яна звяртаецца праз ядро і не можа змяняць узнагароды галасавання.

## Галасаванне

| Узнагарода | Што робіць |
|---|---|
| Дадаць гульню ў спіс | новая пазіцыя з назвы або спасылкі Steam |
| N на гульню са спіса | +N балаў пазіцыі па трохлітарным кодзе |

- Дадаванне можна вярнуць гледачу, пакуль за гульню ніхто не галасаваў; галасы пацвярджаюцца адразу.
- Балы можна перанесці з адной пазіцыі на іншую (напрыклад, калі гульню дадалі двойчы).
- **Новы раўнд:** пераможцу застаецца 1/5 балаў, месцам 2–6 — 2/3, астатнім — без змен. Знізу
  выбывае па адной пазіцыі на кожныя поўныя 5: 6–10 пазіцый — 1, 11–15 — 2 і г. д.

## Усталяванне

Патрэбны Windows, OBS 30+ з уключаным WebSocket-серверам і Node.js 24.

```bash
npm install
npm run build
npm run install-app
```

Праграма ўсталюецца ў `%USERPROFILE%\obs-tadewusz\app`, даныя — у `%USERPROFILE%\obs-tadewusz\data`.
Каманда пакажа, што дадаць у OBS:

1. **Інструменты → Скрыпты:** `app\obs\tadewusz.lua` — праграма будзе запускацца разам з OBS.
2. **Докі → Карыстальніцкія докі браўзера:** `…\obs\start.html?page=dock`.
3. **Крыніцы:** «Tadewusz · Галасаванне» (з’явіцца пасля скрыпту), «Браўзер» з
   `start.html?page=ticker&source=…` для бягучага радка і `start.html?page=music` для музыкі.
   Поўныя адрасы — у доку: «Сістэма → Стан → Адрасы для OBS».
4. **Док → Сістэма → Падключэнне:** Client ID свайго Twitch-прыкладання (тып Public) і ўваход у Twitch,
   пароль OBS WebSocket, Client ID прыкладання Spotify. У Spotify Dashboard дадайце Redirect URI
   `http://127.0.0.1:18745/callback.html`.

## Інтро

Укладка «Інтро» ў доку: кнопка «Стварыць / абнавіць сцэну» стварае ў OBS сцэну «Інтро» з адной
крыніцай-браўзерам 1920×1080 (паўторнае націсканне абнаўляе яе, а не дублюе). Адлік, спасылкі, паўза
паміж кліпамі і паласа данатаў мяняюцца ў доку — оверлей бярэ іх сам, сцэну перастварыць не трэба.

- Кліпы — усе кліпы канала, у тым ліку зробленыя гледачамі, у перамешаным парадку без паўтораў.
  Спіс абнаўляецца пры актывацыі сцэны і кожныя 5 хвілін, пакуль яна ў эфіры.
- Адлік пачынаецца пры актывацыі сцэны; на нулі з’яўляецца надпіс, сцэна сама не пераключаецца.
- Гук кліпаў — праз OBS: гучнасць крыніцы «Tadewusz · Інтро» ў мікшары.
- Фон інтро можна паставіць у любую сцэну: крыніца «Браўзер» з адрасам з дока («Інтро → Фон для іншых сцэн»).

## Аўтра і рэйд

«Інтро / Аўтра → Аўтра»: кнопка «Стварыць / абнавіць сцэну» стварае сцэну «Аўтра» з крыніцай
«Tadewusz · Аўтра» (тая ж старонка інтро ў рэжыме `?mode=outro`). На экране — вялікі надпіс (па змаўчанні
«Хутка сустрэнемся!») і спасылкі з QR (як у інтро або свае), без кліпаў.

Рэйд: «Абраць канал» → спіс каналаў у эфіры, на якія вы падпісаны (пошук, аватар, гульня, назва, гледачы) →
«Пачаць рэйд». Twitch адкрывае акно рэйду ў чаце; на экране справа зверху — картка канала і адлік
(па змаўчанні 10 с). **Raid Now трэба націснуць самому** — Twitch не дае зрабіць гэта праграме; на нулі док
нагадвае пра гэта і дае гукавы сігнал. Без націску Twitch пачне рэйд сам праз ~90 с. Пакуль рэйд не адбыўся,
яго можна адмяніць (і калі яго ўжо адмянілі ў чаце Twitch, «Адмяніць рэйд» закрывае стан у доку). Ліміт Twitch — 10 рэйдаў за 10 хвілін.

Патрэбныя правы Twitch `channel:manage:raids` і `user:read:follows`: калі вы ўвайшлі раней, док папросіць
увайсці зноў.

## Сезон

Укладка «Сезон» у доку: тэма, колькасць, памер, хуткасць, непразрыстасць. Кнопка «Дадаць крыніцу ў OBS»
кладзе празрыстую крыніцу «Tadewusz · Сезон» на ўвесь кадр верхнім слоем у сцэну, якая зараз у праграме.

- Тэмы: «Хэлоўін» (прывіды), «Зіма» (сняжынкі), «Восень» (лісце), «Вясна» (пялёсткі), «Свая» (толькі свае карцінкі).
- Свае карцінкі — PNG, WebP або SVG да 2 МБ, да 20 на тэму; лётаюць разам з аб’ектамі тэмы.
- Пакуль крыніца схаваная, старонка нічога не малюе; кадр — не часцей за 30 у секунду.

## Распрацоўка

```bash
npm test            # тэсты ядра (node:test) і музыкі (Vitest)
npm start           # ядро з даведкай у кансолі
npm run dev         # Vite для дока і оверлеяў (API — ад запушчанага ядра)
```

```
core/       ядро: HTTP, Twitch, OBS, галасаванне, бягучы радок, сховішча
web/        док і оверлеі (Preact, TypeScript); web/src/music — мозг музыкі
shared/     код, агульны для ядра і старонак
obs/        скрыпт OBS, запуск ядра і старонка чакання
tests/      тэсты ядра
docs/       стан праекта, журнал, рашэнні, ідэі і CONTEXT.md для Claude Project
assets/     значкі ўзнагарод Twitch (загружаюцца ўручную ў панэлі Twitch)
```
